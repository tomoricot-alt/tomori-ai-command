# TOMORI AI COMMAND

> **TOMORI -CREATIVE OFFICE- 複数AI統合指揮・タスク管理システム**
> iPhone & PC対応 PWA / React + TypeScript + Vite + Tailwind CSS

---

## 1. 概要

TOMORI AI COMMANDは、ChatGPT・ChatGPT Work・Codex・Claude Code・Gemini・AntigravityなどのAIエージェントを横断的に一元管理し、仕事の依頼・引き継ぎ・進捗確認をひとつの画面で行えるWebアプリケーションです。

### 解決する課題

1. どのAIに何を依頼したか忘れてしまう問題を解消。
2. 複数AIの作業進捗とステータス（実行中・確認待ち・完了等）を一目で把握。
3. 9大項目を網羅した正式な引き継ぎ指示書をワンクリックで生成・コピー。
4. AIごとの利用枠（ChatGPT 5時間枠/週間枠、Claude週次枠/クレジット、Gemini枠）を正確に表示。
5. 推測値と実測値、確認済みと状態未確認を厳格に区別。
6. iPhone Safari (PWA) および PC (3ペイン) 双方に最適化されたモダンUI。
7. 追加課金を一切発生させないローカルストレージ駆動（将来のCloudflare D1接続準備済み）。

## 2. 画面構成

- **PC**: 3ペイン構成
  - **左側**: ナビゲーションメニュー・プロジェクト一覧・停滞タスクアラート
  - **中央**: メインビュー（ダッシュボード / AIチャット指令 / タスク一覧 / AI利用状況 / 成果物一覧 / 設定）
  - **右側**: 進行中タスク・担当AI状況・AIクイック起動リンク
- **iPhone / スマホ**:
  - 下部固定ナビゲーション（ホーム・チャット・タスク・利用状況・設定）
  - PWAホーム画面追加対応（スタンドアロン全画面表示）
  - Safe Area（ノッチ・ホームインジケータ）最適化

## 3. 実装機能一覧

| 機能 | ステータス | 概要 |
|---|---|---|
| **タスク一元管理** | 実装済み・テスト済 | 全AIへの依頼を一覧表示。ステータス・AI・プロジェクト・停滞フィルタ完備 |
| **状態確認バッジ** | 実装済み・テスト済 | 「確認済み」と「状態未確認」を厳密に区別 |
| **AIチャット指令** | 実装済み・テスト済 | 自然言語入力からプロジェクト・推奨AIを自動判定 |
| **9大項目引き継ぎ指示書** | 実装済み・テスト済 | ワンタップコピー＆対象AI画面の即時オープン |
| **AI利用枠モニタ** | 実装済み・テスト済 | `ai_usage_check/latest.json`実測データを完全可視化 |
| **推測不可項目の明示** | 実装済み・テスト済 | ChatGPT通常会話等「専用残量表示なし」を誤認させない設計 |
| **成果物・PR一覧** | 実装済み・テスト済 | GitHub PR、プレビューURL、成果物リンクの横断管理 |
| **停滞タスク監視** | 実装済み・テスト済 | 2時間以上進捗更新のない進行中タスクを自動警告 |
| **データ永続化 & バックアップ** | 実装済み・テスト済 | localStorage保存、JSONエクスポート/インポート |
| **PIN認証画面ロック** | 実装済み・テスト済 | 初期PIN `2026` によるアクセス制限 |
| **PWA対応** | 実装済み・テスト済 | `manifest.json`, `sw.js`, `logo.svg` |

## 4. ローカル起動・開発手順

```bash
cd tomori-ai-command
npm install
npm run dev
```

### ビルドとテスト

```bash
npm run build
npx vitest run
```
